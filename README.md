# Random Splits Overstate Environmental Prediction Performance

Code, results and figures for the paper *"Random Splits Overstate
Environmental Prediction Performance: A Leakage-Safe Benchmark of Tree
Ensembles and Neural Networks on Eight Public Datasets"*.

Random train/test splits are the default evaluation protocol for supervised
learning on environmental tabular data (air quality, rainfall, water quality,
energy consumption), even though such data are temporal and spatially
grouped. This repository quantifies what that choice costs: across eight
public datasets, six model families and ten random seeds, we measure how much
higher the reported performance is under random splits than under
leakage-free temporal and cross-site splits, how the inflation depends on
model capacity, and what happens when hyperparameters are tuned under the
same leaky protocol. Headline result: on the hardest dataset, random splits
inflate R2 by 0.82 for a naive MLP, 0.24-0.36 for tree ensembles, 0.18 for
FT-Transformer, and 0.03 for a linear model - and tuning under the leaky
default widens every one of those gaps.

## Repository layout

```
scripts/               the full pipeline (Python)
  download_data.py     fetch the eight datasets (UCI DOIs + Kaggle), idempotent
  preprocess.py        cleaning -> parquet + manifest + data health report
  benchmark.py         6 models x 3 protocols x 10 seeds, resumable
  tune.py              equal-budget Optuna tuning + tuned re-evaluation
  ft_transformer.py    FT-Transformer baseline (PyTorch)
  stats_analysis.py    Friedman + Nemenyi, leakage-inflation tables
  make_figures.py      journal-grade figures (PNG 300 dpi + vector PDF)
  verify_paper_numbers.py
                       recomputes every number quoted in the paper (51 checks)
data_manifest.json     frozen task/feature/split definitions + excluded
                       leakage columns (regenerated by preprocess.py)
results/               one CSV per experiment; every paper number is a row
figures/               all figures, PNG (preview) + PDF (vector, for print)
```

## Requirements

Python 3.10+ and:

```
numpy, pandas, pyarrow, openpyxl, scikit-learn, lightgbm, xgboost, optuna,
kagglehub, matplotlib, scipy, torch (CPU build is sufficient)
```

Everything runs on a commodity laptop CPU. No GPU is used anywhere.

## Quick start

```bash
pip install numpy pandas pyarrow openpyxl scikit-learn lightgbm xgboost optuna kagglehub matplotlib scipy torch
python scripts/download_data.py     # ~55 MB, idempotent
python scripts/preprocess.py        # cleaning + manifest + health report
python scripts/benchmark.py         # 810 default runs, ~2 CPU-hours
python scripts/stats_analysis.py    # Friedman/Nemenyi + inflation tables
python scripts/make_figures.py      # all figures
python scripts/verify_paper_numbers.py
```

`scripts/tune.py` (equal-budget Optuna tuning, 15 trials x 420 s per
model x dataset) and `scripts/ft_transformer.py` (FT-Transformer baseline)
reproduce the extension experiments; both are resumable and write to their
own CSV files in `results/`.

## Provenance notes

Two target-leakage columns are excluded by construction and documented in
`data/manifest.json`: the CO2 column of the steel dataset (computed from the
target through an emission factor) and the RISK_MM column that some Rain in
Australia derivatives carry. Class prevalence is preserved by stratified
splitting and deliberately not resampled; see the paper's Section 4.
